
========================================================================
Article Title: Spatial isolation slows the recovery of savannah biodiversity more than frequent cultivation in agricultural fallows.
========================================================================

**This repository contains the raw data and R code associated with the article listed above. This allows for full reproduction of statistical analyses done for the study.

------------------------------------------------------------------------
1. PROJECT OVERVIEW
------------------------------------------------------------------------
 
This project evaluates the recovery trajectories of fallows in tropical savannas. It analyzes vegetation community dynamics (richness and cover), habitat structures, and 
soil properties across fallow age and distance as predictor variables.

------------------------------------------------------------------------
2. FILE & DIRECTORY STRUCTURE
------------------------------------------------------------------------
Below is a description of the files included in this project directory:

RScripts:

* Fallow_recovery_project_analysis_code.R    - Main R script containing data processing, statistical analysis, and visualization.


Data Files:
* richness_cover_fallow.csv                 - Species richness and percentage cover data for fallows.
* richness_cover_OG.csv                     - Species richness and percentage cover data for Old Growth savannahs.
* habitat variables.csv                     - Habitat structure variables collected at study sites.
* Soil_PCA_master.csv                       - Soil properties collected at study sites.
* PCA scores for analysis.csv               - Extracted Principal Component scores used as predictors in analysis.
* DissimiData_no_UI.csv                     - Extracted Community dissimilarity data for fallows and Old-growth savnnahs.
